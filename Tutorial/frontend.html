Frontend

¿Qué es el Frontend?

El frontend es la parte de una aplicación que el usuario ve e interactúa directamente. Incluye la estructura visual, los colores, los botones, las animaciones, los formularios y la respuesta a cada clic.

Se conoce como lado del cliente porque su código se ejecuta en el navegador. Su objetivo es ofrecer una experiencia clara, atractiva y funcional.

¿Desde cuándo existe?

  • 1991: aparece la primera página web con HTML básico.
  • 1995: JavaScript permite reaccionar a clics y validar formularios.
  • 1996-1999: CSS separa el diseño del contenido.
  • 2005: AJAX permite cargar datos sin recargar la página.
  • 2010 en adelante: crecen React, Vue, Angular y las SPA.

Características principales

  • Interactividad: responde a las acciones del usuario.
  • Responsive: se adapta a móviles, tablets y escritorios.
  • Accesibilidad: puede ser utilizado por cualquier persona.
  • Rendimiento: carga rápido y consume pocos recursos.
  • Compatibilidad: funciona en distintos navegadores.
Dato clave: el frontend trabaja con el backend mediante APIs y el modelo petición-respuesta.

Todo desarrollador frontend debe conocer estos tres lenguajes base y sus herramientas modernas:

HTML5

Lenguaje de marcado que define la estructura: títulos, párrafos, imágenes, enlaces y formularios.

Año 2014 · estructura

CSS

Lenguaje de estilos que controla colores, tipografías, márgenes, animaciones y diseño responsive.

Año 1994 · apariencia

JavaScript

Lenguaje de programación que añade eventos, peticiones a APIs, animaciones y validaciones.

Año 1995 · comportamiento

React

Librería de Meta para crear interfaces mediante componentes reutilizables.

Componentes · SPA

Vue.js

Framework progresivo, flexible y fácil de aprender para construir interfaces web.

Progresivo · flexible

Angular

Framework de Google con una estructura completa para aplicaciones empresariales.

Robusto · empresarial
Regla de oro: aprende bien HTML, CSS y JavaScript puro antes de saltar a un framework.

Ejemplo práctico de Frontend

Este ejemplo combina HTML, CSS y JavaScript en una sola página:

<h1>Mi primer Frontend</h1>
<p id="contador">0</p>
<button onclick="sumar()">Sumar +1</button>

<script>
	let cuenta = 0;

	function sumar() {
		cuenta++;
		document.getElementById('contador').textContent = cuenta;
	}
</script>

¿Qué hace este código?

  • HTML: crea el título, el contador y los botones.
  • CSS: define color, tamaño, espaciado y alineación.
  • JavaScript: escucha el clic y actualiza el contador.
