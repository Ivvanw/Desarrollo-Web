CSS: Hojas de Estilo en Cascada

¿Qué es CSS?

CSS significa Cascading Style Sheets. Es un lenguaje de estilos que define la apariencia visual de un documento HTML: colores, tipografías, tamaños, márgenes, posiciones, animaciones y diseño responsive.

CSS no es un lenguaje de programación. Su función es separar el contenido de HTML del diseño, facilitando el mantenimiento y la reutilización de estilos.

¿Desde cuándo existe?

  • 1994: Håkon Wium Lie propone las hojas de estilo en cascada.
  • 1996: se publica CSS1 por el W3C.
  • 1998: aparece CSS2 con posicionamiento y medios.
  • 2011 en adelante: CSS3 se divide en módulos como flexbox, grid y animaciones.
  • 2023 en adelante: crecen container queries, nesting y nuevas variables.

Características principales

  • Cascada: los estilos se aplican según un orden de prioridad.
  • Herencia: algunos estilos pasan de padres a hijos.
  • Especificidad: las reglas más específicas tienen prioridad.
  • Reutilización: una clase puede usarse en muchos elementos.
  • Responsive: adapta el diseño a cualquier pantalla.
  • Modularidad: CSS3 se organiza en módulos independientes.
Dato clave: el nombre “cascada” indica que el navegador decide qué regla aplicar siguiendo un orden jerárquico.

Formas de escribir y distribuir CSS

Estas son las formas más importantes de usar estilos en un proyecto:

CSS en línea

Se escribe directamente en la etiqueta HTML usando el atributo style.

<p style="color: red;">

CSS interno

Se coloca dentro de una etiqueta <style> en el <head>.

<style> p { color: red; } </style>

CSS externo

Se guarda en un archivo `.css` y se enlaza con <link>. Es la opción recomendada.

<link rel="stylesheet">

Preprocesadores

Extienden CSS con variables, funciones y anidación.

Sass · Less · Stylus

Frameworks CSS

Incluyen estilos predefinidos para acelerar el desarrollo.

Bootstrap · Tailwind · Bulma

Metodologías

Convenciones para escribir CSS ordenado y escalable.

BEM · OOCSS · SMACSS
Regla de oro: aprende CSS puro antes de saltar a un framework o preprocesador.

Ejemplo práctico de CSS

Este código transforma un HTML simple con colores, espaciado, sombras y transiciones:

<style>
	.tarjeta {
		padding: 30px;
		background: white;
		color: #764ba2;
		border-radius: 15px;
		box-shadow: 0 10px 30px rgba(0, 0, 0, 0.3);
		text-align: center;
	}

	.boton:hover {
		background: #764ba2;
	}
</style>

Hola CSS

Este diseño fue creado con colores, sombras, bordes y transiciones.

¿Qué hace este código?

  • .tarjeta: crea una tarjeta con fondo, bordes y sombra.
  • .boton: aplica estilos al botón.
  • :hover: cambia el estilo cuando el cursor pasa encima.
  • transition: suaviza los cambios visuales.
  • box-shadow: agrega profundidad al elemento.
Tip: abre las DevTools con F12 para modificar estilos CSS en vivo.
