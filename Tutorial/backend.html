Backend

¿Qué es el Backend?

El backend es la parte de una aplicación que el usuario no ve directamente. En el servidor se ejecutan la lógica de negocio, el acceso a bases de datos, la autenticación, el procesamiento de datos y la seguridad.

Su objetivo es recibir peticiones del frontend, procesarlas y devolver respuestas.

¿Desde cuándo existe?

  • 1960-1970: el procesamiento se realizaba en mainframes.
  • 1991: aparece el primer servidor web con la Web.
  • 1995-2000: se popularizan PHP, ASP y Java Servlets.
  • 2005-2010: crecen los frameworks MVC y las APIs REST.
  • 2010 en adelante: aparecen Node.js, Docker, microservicios y serverless.

Características principales

  • Seguridad: autenticación, permisos y cifrado.
  • Escalabilidad: atención de muchos usuarios.
  • Persistencia: almacenamiento y recuperación de datos.
  • Lógica de negocio: reglas y validaciones.
  • Integración: conexión con otras APIs y servicios.
Dato clave: el frontend pide y el backend responde. Juntos forman el modelo cliente-servidor.

Bases de datos

  • MySQL / MariaDB: bases de datos relacionales.
  • PostgreSQL: relacional avanzada y robusta.
  • MongoDB: NoSQL que almacena documentos JSON.
  • Redis: base en memoria para caché.
  • SQL Server y Oracle: soluciones empresariales.
Regla de oro: aprende SQL y una base de datos relacional antes de pasar a NoSQL.

Backend con Node.js y Express

Este servidor recibe peticiones y responde con datos en formato JSON:

const express = require('express');
const app = express();
const PORT = 3000;

app.use(express.json());

app.get('/api/usuarios', (req, res) => {
	const usuarios = [
		{ id: 1, nombre: 'Maria', rol: 'Frontend' },
		{ id: 2, nombre: 'Sebastian', rol: 'Backend' },
		{ id: 3, nombre: 'Pancho', rol: 'Full Stack' }
	];

	res.json(usuarios);
});

app.listen(PORT, () => {
	console.log(`Servidor en http://localhost:${PORT}`);
});

Demo funcional

Simula una petición GET /api/usuarios y muestra la respuesta del servidor.

Presiona el botón para consultar usuarios.

¿Qué hace este código?

  • Express: simplifica la creación de servidores web.
  • app.get(): define una ruta para peticiones GET.
  • res.json(): envía datos en formato JSON.
  • app.listen(): inicia el servidor en un puerto.
Conexión frontend + backend: desde HTML puedes consumir esta ruta con fetch('http://localhost:3000/api/usuarios').
