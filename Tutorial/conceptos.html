Evolución de los sistemas computacionales

¿Qué es un Mainframe?

Un mainframe es un computador de gran capacidad diseñado para procesar enormes cantidades de datos y ejecutar muchas operaciones de forma simultánea, segura y confiable.

Se utiliza en bancos, entidades gubernamentales, compañías de seguros, aerolíneas y grandes organizaciones.

Características principales

  • Alta capacidad de procesamiento.
  • Procesamiento de grandes volúmenes de datos.
  • Alta seguridad y confiabilidad.
  • Funcionamiento continuo las 24 horas.
  • Soporte para miles de usuarios simultáneos.
Origen: Se desarrolló y popularizó durante la década de 1960.

¿Qué es una Terminal Bruta?

Una terminal bruta es un dispositivo sin capacidad significativa de procesamiento ni almacenamiento. Permite ingresar datos y visualizar la información procesada por un computador central.

Depende completamente del mainframe o servidor para ejecutar programas, realizar cálculos y almacenar información.

Características principales

  • No realiza procesamiento complejo de manera independiente.
  • No requiere almacenamiento local significativo.
  • Depende de un computador central.
  • Permite ingresar comandos y datos.
  • Muestra los resultados enviados por el sistema central.
Periodo: Se popularizó durante las décadas de 1960 y 1970.

¿Qué es el modelo Cliente-Servidor?

Es una arquitectura en la que los clientes solicitan recursos o servicios y los servidores los proporcionan y procesan.

Modelo petición-respuesta

  1. El cliente envía una petición al servidor.
  2. El servidor recibe y procesa la petición.
  3. El servidor devuelve una respuesta.
  4. El cliente presenta el resultado al usuario.

Ventajas

  • Centralización de datos y recursos.
  • Escalabilidad para añadir clientes o servidores.
  • Control de seguridad desde el servidor.
Consolidación: Se extendió en los años 80 con las redes locales.

Arquitectura de 2 niveles

Es la forma básica del modelo cliente-servidor. Tiene dos capas que se comunican directamente: el cliente y el servidor.

Capas

  • Cliente: contiene la interfaz y envía peticiones.
  • Servidor: almacena la base de datos y ejecuta la lógica.

Características

  • Comunicación directa entre cliente y servidor.
  • Implementación sencilla para sistemas pequeños.
  • Escalabilidad limitada con muchos usuarios.
Periodo: Se popularizó en los años 80 y 90 con aplicaciones conectadas directamente a bases de datos.

Arquitectura de 3 niveles

Divide la aplicación en tres capas independientes: presentación, lógica de negocio y datos. Esto facilita la escalabilidad, la seguridad y el mantenimiento.

Las tres capas

  1. Presentación: interfaz con la que interactúa el usuario.
  2. Lógica de negocio: valida datos y ejecuta las reglas.
  3. Datos: almacena y gestiona la información.

Ventajas

  • Mayor escalabilidad y rendimiento.
  • El cliente no accede directamente a la base de datos.
  • Mantenimiento independiente de cada capa.
Popularización: Se extendió a finales de los años 90 con el auge de las aplicaciones web.

Arquitectura multinivel

La arquitectura multinivel divide una aplicación en múltiples capas independientes, cada una especializada en una función.

Capas típicas

  • Presentación: interfaz web, móvil o de escritorio.
  • Servicios web o API: entrada al sistema.
  • Lógica de negocio: reglas y procesos.
  • Acceso a datos: comunicación con la base de datos.
  • Persistencia e infraestructura: almacenamiento, servidores y colas.

Ventajas

  • Escalabilidad independiente de cada capa.
  • Alta disponibilidad y tolerancia a fallos.
  • Seguridad reforzada y mantenimiento distribuido.
  • Ideal para microservicios y computación en la nube.
Expansión: Su auge comenzó en los años 2000 con Internet, la nube y los microservicios.
