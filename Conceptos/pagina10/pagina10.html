CSS cascade style sheets

CSS (Cascading Style Sheets) es un lenguaje de hojas de estilo utilizado para describir la presentación de un documento HTML o XML. Permite separar el contenido de la presentación, lo que facilita el diseño y mantenimiento de sitios web. Con CSS, se pueden definir estilos para elementos HTML, como colores, fuentes, márgenes, bordes y mucho más. Además, CSS permite la creación de diseños responsivos que se adaptan a diferentes tamaños de pantalla y dispositivos.
